# 首次配置与固定资产

Agent首先报告工具包路径，并取得真实源码根目录和固定资产绝对路径；没有路径就询问，不默认本包。多次使用/升级通过同一个--asset-root或REQMGR_ASSET_ROOT定位，不重新初始化。

独立路径可在本机另一固定目录、服务器磁盘或已挂载NAS/共享盘。Windows示例D:/Assets/Requirements、Linux示例/data/assets/requirements仅为示例，必须替换真实路径。网络目录须已挂载并支持原子替换及排他写入；本包不处理连接/登录或自动云上传。

在工具包目录运行（python3或Windows python）：

```bash
python3 -B scripts/reqmgr.py --asset-root /data/assets/requirements init --source-root /data/projects
python3 -B scripts/reqmgr.py --asset-root /data/assets/requirements info
python3 -B scripts/reqmgr.py --asset-root /data/assets/requirements discover
```

init只允许新空目录；已有资产运行info。多个源码根目录重复--source-root。info打印实际工具包、固定资产、源码根目录、登记文件、总览和周索引路径。脚本拒绝相对资产路径、包内资产、包含包的资产父目录、源码内资产和符号链接越界。

项目登记由Agent根据发现目录/README完成。register --stdin接收项目数组；格式见config/projects.example.json。该文件只是只读模板，不在包内写实际配置。实际登记保存资产/.reqmgr/config.json；不能删除已有需求关联的项目ID。根目录只发现直接子目录，嵌套项目按真实路径手工登记。

可为当前终端固定资产定位：

```bash
export REQMGR_ASSET_ROOT=/data/assets/requirements
python3 -B scripts/reqmgr.py info
```

Windows PowerShell：

```powershell
$env:REQMGR_ASSET_ROOT = 'D:/Assets/Requirements'
python -B scripts/reqmgr.py info
```

环境变量只提供明确路径，没有默认位置；未设置也可每次传--asset-root。路径与配置不包含Token或密码。首次初始化、进度更新和日常归档都不能向工具包写产物。

初始化 v3 固定 archive_year（初始化年份）。已有 v2 配置将拒绝日常写入，请先按迁移说明迁入独立空资产，核验后显式切换长期路径。
