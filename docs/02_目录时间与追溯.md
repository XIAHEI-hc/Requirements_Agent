# 目录、时间与追溯

| 固定资产中的路径 | 用途 |
|---|---|
| 资产说明.md | 固定目录与资产身份 |
| 需求总览.md | 全部需求当前状态及周总汇入口 |
| 周总汇/月/周/每周需求总汇.md | 全部项目该周统计、进度和遗留表 |
| 项目/pixlab/需求/月/周/日期/需求.md | 单项目需求当前文档 |
| 项目/pixlab/需求索引.md | 项目内建议排序和实施进度 |
| 项目/pixlab/周总汇/月/周/每周需求总汇.md | 项目内周表 |
| 待归属/月/周/日期/需求.md | 未明确项目条目 |
| 修订历史/REQ-…/r0001.md | 需求各修订文档 |
| 代码依据/SRC-….json | 只读版本核查结果 |
| .reqmgr/config.json | 固定资产和项目登记 |
| .reqmgr/records、revisions | 当前记录和不可覆盖的结构化修订 |
| .reqmgr/changes.jsonl、operations | 规范化变更原因和批次状态 |

没有原始输入/intakes/staging目录。一个消息用EV时间事件关联拆分需求，EV不含原话；追溯依据是稳定ID、消息时间、整理时间、代码证据和修订原因。

北京时间Asia/Shanghai；消息实际时间优先，其次用户提供时间，缺失用系统接收时间并注明。周一至周日，跨月/年周归周一月份，例如2026-11-01属于2026-10/2026-10-26_至_2026-11-01/2026-11-01。

补充需求保留首次时间、ID和原文件路径，最新整理时间另记；历史版次不覆盖。历史周总汇按当周截点前已记录的修订恢复，晚录入且无当时记录的需求以待核实展示，不能把现在进度伪装成以前进度。
