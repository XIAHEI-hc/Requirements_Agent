# 需求管理 Agent v2.0

你随口表达需求，AI识别项目、只读理解代码，形成Markdown并管理进度与每周总汇。**严禁修改业务代码。**

## 第二版变化

- 不再保存原话或原话哈希，只记录整理后的需求、时间和修订依据。
- 每周自动生成跨项目和项目内总汇，包含新增、更新、完成和历史未完成项。
- 实施进度与需求确认分开；未开始蓝色、未完成橙色、已完成绿色，未知灰色。
- 长期需求资产与Agent包、源码完全分离；没有明确固定目录就不能归档。
- 支持从v1当前需求导入新资产，默认不读取、不复制原话文件。

## 三类目录各自固定

| 类型 | Windows示例 | Linux示例 |
|---|---|---|
| Agent包（工具与Skills） | D:/Tools/Requirements_Agent_Starter_v2 | /data/tools/requirements-agent-v2 |
| 源码根目录（只读） | D:/Projects | /data/projects |
| 长期需求资产（产物） | D:/Assets/Requirements | /data/assets/requirements |

资产也可以是已挂载的NAS/共享盘目录。本包不要求建立云平台，也不会默认把资产放在包内部。“独立资产”指独立固定路径，不能用包内相对data。

## 开始

1. 解压工具包到独立工具目录。
2. 将START_HERE_给AI的启动指令.md中的整段指令给AI，并告诉它真实源码根目录和固定资产绝对路径。
3. AI先声明三类路径，初始化/读取资产登记，然后处理自然语言。你无需手写JSON。
4. 从资产根目录的需求总览.md、周总汇/索引.md查看需求和每周进度表。

Python3.10+，仅标准库；Git版本证据需Git。用python -B运行工具。无需pip、Docker、前端或服务。Codex/Claude/DSH需要真实文件工具；纯聊天不能落盘。Skills随包携带，不自动安装到个人目录。

包里只有工具、规则、模板和静态示例；真实产物不在这里。升级包后继续使用同一个--asset-root。详细初始化、颜色兼容、历史截点和迁移说明见docs/。
