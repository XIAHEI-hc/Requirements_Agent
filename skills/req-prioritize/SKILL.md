# req-prioritize

读取禁令，严禁业务代码改造、不保存原话。读取项目归属索引及需求依据，不新建项目归档目录。
按影响、紧急程度、阻断和依赖建议 P0-P3；未知待评估，表中显示未设置，不从语气/新时间武断 P0。
通过 apply 新修订保存建议与理由。用户明确确认才填 priority_confirmed、priority_confirmation，变更优先级未重新确认自动撤销确认标志。
主状态与优先级独立；已确认不等于已解决。自动刷新项目归属索引中的分组排序及周表；不移动需求文件。
