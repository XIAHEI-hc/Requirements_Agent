# req-weekly

读取 ../../agent/PROHIBITIONS.md，先 info 声明独立资产路径。严禁业务代码改造、不保存原话。
运行 weekly --week YYYY-MM-DD 或 weekly。输出与需求同目录，文件名 本周需求总汇.md；不创建项目总汇目录或日期子目录。工作周周一至周五，跨月归周一所在月，周末默认归前一工作周。
读 ../../docs/03_进度颜色与每周总汇.md。标题 MM.DD-MM.DD 本周需求总汇，含工作周、最后同步时间、状态统计、本周完整需求、大型需求与子需求进度、跨周补充与推进。状态使用 ⚪ 未开始、🟡 进行中、🔴 已阻塞、🟢 已解决、⚫ 已取消，不依赖 HTML 染色。
按 archive_week 统计新增顶层；五个状态数仅统计顶层，有效子项另计且不含已取消。用户指定未来归档周应按指定周计入，不按提前创建日计数。旧需求本周推进只写跨周，不增加本周新增。
原归档周表始终显示最新状态，不使用历史周末截点；当时进展查修订历史。不能只改周表，先 req-archive 新修订登记依据。
回报周表路径、顶层与子项统计、跨周推进和待澄清项。不安排开发执行、不假称已安装定时任务。
