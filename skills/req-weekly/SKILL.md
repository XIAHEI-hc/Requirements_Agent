# req-weekly

读取禁令，严禁业务代码改造、不保存原话。先info说明独立资产路径。
使用weekly --week日期或当前weekly；脚本按周一至周日重建，包含新增/更新/完成及之前遗留未完成项。没有新需求的周也保留遗留。
阅读表格的蓝色未开始、橙色未完成、绿色已完成，未知灰色。HTML样式不支持时依赖图标+文字；不承诺所有Markdown阅读器显示相同文字色。
状态变化需先用req-archive记录依据，不能只改周表。历史周用当时已记录修订，不能将今天状态写成过去状态。统计和限制见../../docs/03_进度颜色与每周总汇.md。
回报总汇路径、各状态统计、遗留与待澄清；不安排开发执行、不假称定时任务已经安装。
